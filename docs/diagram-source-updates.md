# Shared source updates

`DiagramSourceUpdateService` is the internal engine portion of CORE-9/10/11, joining `DiagramRelationshipIdentityMap` to retained routing. It is independent of LiveEditor and feature switches. AF now uses it in the LiveEditor Enterprise grid-preview worker; the integration is described in [liveeditor-retained-preview.md](liveeditor-retained-preview.md).

## Lifecycle and publication

Capture a valid parsed flowchart contract (including the Enterprise mapper's output), its completed authoritative cell layout, document ID, source revision and source text. Capture detaches the model/layout and replaces parser route IDs with the stable relationship bindings. Each parsed edge must have a unique nonempty parser ID and exactly one accepted route; unsupported/invisible inventories require a different session entry path.

Call `ObserveSourceRevision` on every edit, including invalid text, before dispatching analysis. After successful analysis call `Prepare(documentId, revision, text, model, options)`. Preparation forks the accepted state and returns a candidate with classification, affected/rebuilt route IDs, identity policy notices and any failure reason. It does not publish or modify caller-owned parser inputs. `TryCommit` checks instance ownership, the current observed source revision and accepted-layout revision, then accepts text, full source model, identities and retained geometry together. Duplicate commits and competing/superseded candidates fail. Discarded candidates do not consume stable identities.

`CopyCandidateSnapshot` returns detached source/geometry for an owned, successful candidate without accepting it, so a host can draw, rasterise and validate preview metadata before calling `TryCommit`. Discarding a failed drawing leaves the accepted state intact.

`CopySnapshot` returns detached geometry and a complete source/presentation contract using the stable IDs. Source spans, declarations, styles, configuration, interactions and identity bindings belong to that same accepted source revision. Resolved guides refer to the full snapshot edges. It performs no initial placement or route rebuild. `SourceRevision` identifies the accepted source; `ObservedSourceRevision` and `IsStale` identify later unaccepted text. The host keeps the user's current typed script and displays a candidate's failure reason; the service never replaces the script with accepted text.

Call `Invalidate(reason)` when switching documents/options or starting explicit Auto layout, then create a new instance from the new authoritative layout. Retirement is permanent, including for in-flight candidates. A replacement instance rejects old candidates even when document IDs and revision numbers happen to match. Option mismatches report a rebuild requirement; preparation never silently replaces an instance.

## Classification and local operations

| Edit | Result |
| --- | --- |
| Comments, whitespace, parser ID/order changes, source spans, hint diagnostics, interactions | Metadata-only; no route rebuild |
| Inline fill/stroke/text colour, existing class/link colour definitions, animation | Redraw; preserve accepted geometry |
| Node placement hint addition/replacement/removal, supported push hint | Local transaction using fixed cell spans; NW/NE/SE/SW support independent gaps; `at row column` needs no peer |
| Relationship addition/removal/reconnect or endpoint/travel hint change/removal | Local transaction with stable surviving IDs; `leave E@step` / `enter W@step` retain exact usable connection points |
| Ungrouped node insertion/removal in a diagram without groups | Local measured cell reservation/removal, hint resolution and affected-route closure; may arrive with relationship changes |
| Ungrouped node label/measured-size changes | Local cell sizing and dependent-hint resolution; preserve fitting spans and grow only as needed |
| Plain relationship label changes | Redraw with stable identity; the host measures text placement and requests only demonstrated route dependencies before publication |
| Direction/kind/options/configuration changes, group edits, grouped insertion/removal/sizing, fonts/text format, shapes, marker/kind/constraint changes | Explicit rebuild requirement; no rebuild executed |
| Ambiguous identities, invalid analysed model, stale/retired instance, impossible supported local edit | Rejected; retain accepted state |

Mixed supported changes replace routing inputs and plan all changed hints before computing one dependency closure. They publish together or fail together. New relative hints resolve their changed peers first; existing relative-hint dependents move with a changed anchor. Above/below/left/right use the peer's start alignment, owner/peer spans and whole-cell offset, matching existing cell-hint conventions. NW/NE/SE/SW resolve both axes from the peer's corresponding boundaries, with independent nonnegative vertical and horizontal cell gaps; the second gap defaults to the first. Changing either gap is a local source update, and relationship routes remain orthogonal. See [diagonal-placement-hints.md](diagonal-placement-hints.md). Cycles, missing node peers, coordinate overflow and occupied cells reject the edit. Hint removal releases the lock without rearranging the diagram. Push uses the frozen sibling envelope and existing cell checks; complex simultaneous push dependencies may reject rather than seek an arrangement. Group peers, group moves/refitting and automatic collision displacement are outside this slice.

The engine validates retained hints and cell/semantic constraints, includes incident and newly obstructed routes, expands for terminal redistribution and applies the existing bounded route completion and independent legality checker. A failed local edit stays rejected; it cannot turn into a full rebuild. Adding/reconnecting plateau-to-plateau triggering relationships requests a new semantic constraint session: the old convention snapshot must not validate a changed timeline. Grouped sizing/insertion/removal and manual port-slot order remain future work. GUI undo/redo uses the existing source path. Ungrouped plain node labels use local measured sizing. Fonts/text formats and unsupported style geometry changes still request explicit rebuilding. A grouped member's source pin may now use vacant cells inside its frozen ancestor frames, with inset/title checks and exact undo. Membership changes and group refitting remain unsupported local operations.

## Validation

Relationship removal deletes its route and guide while retaining surviving node/route geometry and vacant connection slots. Ordinary removal rebuilds zero routes. A surviving route whose forward/back-edge classification changes enters the dependency set; subsequent terminal changes expand it normally under the route budget. Removing the last relationship retains the placed canvas with an empty route/guide inventory. Mixed removal and supported edits publish together or reject together. Plateau timeline changes and invisible layout constraints still require an explicit new construction/semantic session. Undo can re-add a deleted declaration locally; surviving identities stay stable, while the re-added line receives a new identity under the documented text-reconciliation policy. See [diagram-source-identities.md](diagram-source-identities.md).

`at <row> <column>` resolves directly to a signed logical-cell origin before dependent relative hints are evaluated. Its row/column spans remain fixed; collisions and semantic constraints still reject the transaction. Newly introduced absolute pins remember their pre-pin origins within the retained session. `Prepare` also accepts optional `CapturePlacementOrigins: true` (after `RouteLimit`) to remember the origin when any first active placement hint is added. LiveEditor enables this for typed and GUI edits so undoing a first hint restores the original position and resolves dependents. Without this option, ordinary relative-hint removal retains its previous release-lock behavior. Removing a remembered hint restores its origin; a new session loaded with an existing hint has no prior origin. All origin records belong to isolated candidate state and publish only with successful edits. See [anchor-free-placement.md](anchor-free-placement.md).

The LiveEditor integration now runs after Enterprise analysis in its single worker, draws fresh SVG/PNG from candidate geometry, and publishes only the current source/document/options request. It preserves typed text, stale-preview reasons, the camera and accepted export bytes. Text undo/redo and grid-snapped GUI node drops enter that same path. Node gestures project retained cells without routing during movement; a release writes one undoable source hint. Relationship/port adapters and group gestures remain pending; see [liveeditor-retained-preview.md](liveeditor-retained-preview.md).

Ungrouped source additions use measured whole-cell spans and preserve every existing reservation. A deterministic search of at most 64 row candidates chooses a temporary free reservation beyond the rightmost column, respecting semantic band order. The complete transaction then resolves explicit absolute/relative/quadrant hints and their dependents before routing. Automatic placement never moves earlier nodes. A collision, unavailable band position, coordinate overflow or route-budget failure rejects the entire addition rather than rebuilding. New obstacles seed existing routes near their bounds; unrelated paths remain exact. Node-specific Enterprise presentation facts now participate in per-node classification, while automatically generated paint-only style entries do not force global rebuilding. Styling/font changes without a supported local sizing operation still request an explicit rebuild.

Ungrouped source removal retains surviving cells, routes and vacant slots. The model must remove incident relationships as well; a remaining declaration rejects the transaction. Deleting the last node leaves a valid empty retained session. Isolated region records restore unhinted nodes on undo, including after an empty canvas; grid gaps/configuration and the model coordinate origin remain stable. First-placement origins survive deletion/undo, so an earlier move can still be undone. Re-added relationship declarations follow the existing new-identity policy. Grouped removal/refitting and plateau triggering changes remain explicit construction/session changes.

Self-relationships are supported by direct/source additions and reconnects. They use the same dependency closure and exact-point validation; a loop cannot reserve one point for both ends. Labeled loops reserve measured straight-segment room using bounded outside-node candidates that preserve terminals, mandatory travel and neighboring route quality. An unavailable legal candidate rejects the local transaction. Initial layout seals loop label space before publishing final guides, fixing later completion erasing earlier reservations.

Node label/size updates plan cell spans against measured dimensions before resolving hint dependents. Fitting reservations remain unchanged, including grown internal gaps; growth uses the minimum additional rows/columns without moving unrelated owners. Bounds changes seed incident/newly obstructed routes. Size histories restore exact prior spans on undo/redo and survive node deletion; coalesced hint removal restores position while retaining the requested label's span. New cell collisions, nonfinite/overflowing dimensions, proportional-body sizing failures and frozen-frame clearance violations reject atomically. Grouped sizing/font/format changes remain explicit rebuild cases.

Plain relationship text changes report `ChangedLabelIds` independently of actual rebuilt routes. The drawing host must validate the candidate text before commit: the shared service alone does not measure Enterprise drawing labels. LiveEditor freezes placements outside the affected set, measures straight-run room, node/frame clearance, label overlap and routes through labels, and requests bounded `AdditionalRouteSeeds` only for demonstrated conflicts. Changed text must be placeable; unrelated baseline issues may remain but cannot worsen. Failure preserves the accepted source/geometry and the host's typed script. This path performs no initial placement or global routing fallback.

Accepted label scenes retain immutable, structurally shared path/label records. An exact earlier semantic/body/cell request can replay its accepted routes and text placements for undo/redo without rebuilding them. Restoration independently checks body/cell geometry, stable route inventory, actual connection points, mandatory hints and route findings before publication. These session checkpoints are not a file persistence format; memory scaling remains part of the benchmark work. Default font metrics retain the renderer's character-width approximation; supported numeric link font sizes now drive both measured envelopes and painted line spacing. This is not a glyph-level measurement guarantee.
