# Previewing a placement improvement (AG)

Enable AG in experimental settings, then choose **View → Suggest placement improvement…** on a current Enterprise grid preview. Select a relationship to investigate it, or a connected element to investigate its incident routes. With nothing selected, the command starts from the most concerning measured route. AF and AH can remain off; AF continues to own mouse drag gestures.

The command uses the existing background render worker. You can keep editing while it searches; a source, document or option change cancels the old result. It searches a bounded set of retained cell moves, with route/terminal trials first and complete-diagram scoring. A limit or no-improvement result appears in the status bar without changing the diagram. The placement command offers source-persistable node moves. A measured route-only improvement is reported separately if no node placement qualifies.

The review shows the accepted and proposed diagrams side by side. Both support zoom/pan. Totals include bends, crossing pairs, actual SVG width, moved-node count, displacement and remaining route findings. The proposed source edit is preflighted through an isolated copy of the normal source/geometry/label pipeline. Relative dependents may follow their peer; the displayed totals and change set include their actual movement. New label conflicts, broken constraints and candidates requiring initial layout are rejected before review. The new pin does not earn a hint-score bonus during quality comparison.

**Cancel** leaves source, accepted geometry, labels, exports and history exact. **Apply** writes one undoable `at row column` hint and enters the ordinary source worker. It does not publish the detached preview directly or start another routing worker. Current source/layout/document/options checks prevent applying an older review. Tests require the ordinarily published SVG and geometry to match the preflight, with zero initial placement. Undo/redo restore the corresponding accepted arrangements.

The source adapter preserves labels, quoted hint words, comments, classes and line endings, and refuses to overwrite an existing mandatory placement hint. Notes and contained members can retain absolute cell pins. A contained-member update must remain inside every frozen ancestor frame, preserve canonical inset and avoid title strips; it cannot refit a frame or change membership. Group frame pins, grouped insertion/removal/sizing and grouped mouse gestures retain their separate operation boundaries.

Saving source persists the chosen node pin. Reloading runs initial construction with that mandatory cell position; underdetermined route tracks and unpinned nodes may be chosen again, and group frames may be derived again. Copy/export from the main preview always uses the accepted arrangement. Auto layout remains an explicit new-arrangement operation.

The small native dialog has been rendered and visually inspected (`out/suggestion-preview-dialog.png`). This verifies that dialog's diagrams, metrics and controls, not the broader large-diagram visual/readability rollout. Full-scene copying/scoring and source/label preflight still need the plan's latency and memory benchmarks. All experiment defaults remain off.
