# MSAGL layout trial

This folder compares the current custom router with official Microsoft Automatic Graph Layout (NuGet `Msagl` 1.2.1) behind one shared layout interface.

## Engines

| Folder | Engine |
| --- | --- |
| `custom/` | Current native Sugiyama placement and custom shared router |
| `msagl-rectilinear/` | Official MSAGL layered layout with the rectilinear obstacle router |
| `msagl-spline/` | Official MSAGL layered layout with the spline obstacle router |

Pictures for the web-shop diagram (flowchart and enterprise paint of the current custom router), the order-suite diagram, the sales-team diagram, and the full catalogue-plus-sample gate set are written here after `FlowchartLayoutFixRender msagl-trial`.

Gate counts, visual notes, licence, package size, and the switch recommendation are filled in after the trial render.
